# SpaceX Falcon 9 Landing Prediction
This repository contains the final project for the IBM Data Science Professional Certificate. The project demonstrates the full data science lifecycle, including:
- **Data Collection:** Web scraping data from Wikipedia.
- **Data Wrangling:** Cleaning and formatting launch data.
- **Exploratory Data Analysis (EDA):** Using Python/Pandas and SQL.
- **Data Visualization:** Interactive maps (Folium) and dashboards (Plotly Dash).
- **Predictive Modeling:** Applying classification algorithms (Logistic Regression, SVM, Decision Trees, KNN) to predict landing success.
